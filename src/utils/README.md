# utils

Demonstration and test utilities for UI features, themes, icons, and reporting. These are reference programs exploring Genero's visual capabilities rather than core business logic.

## Modules

| Module | Description |
|--------|-------------|
| fontAwesome.4gl | FontAwesome icon viewer with search filtering, reading `image2font.txt`. |
| gbc_theme.4gl | GBC theme viewer that parses and displays `main-definition.json`. |
| gre_test4rp.4gl | Genero Report Engine test tool for running `.4rp` reports with various output devices. |
| icons_2_image2font.4gl | Generates an `image2font.txt` mapping from FontAwesome 5 JSON icon data. |
| matDesTest.4gl | Material Design showcase — colours, icons, forms, progress bars, GBC features. |
