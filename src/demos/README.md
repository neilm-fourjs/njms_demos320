# demos

Standalone demonstration programs showcasing Genero BDL UI features, web components, charting, and dialog patterns. Each `.4gl` is paired with a like-named `.per` form where relevant.

The folder has three obvious groupings:

- **`wc_*`** — Web Component demos (charts, calendars, gallery, maps, custom SVG widgets).
- **`wizard_*`** — Multi-step wizard demos illustrating different dialog interaction patterns (drag-and-drop, multi-row select, single-dialog, multi-dialog).
- **`widgets*`** — Canvas-drawing widgets (charts, clock) plus a general widget showcase.
